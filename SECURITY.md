# Security

Kinuvo runs Agents that can execute commands, read files and control a computer, so security reports matter.

Report vulnerabilities privately through GitHub: **Security → Report a vulnerability** on this repository. Do not open a public issue. Include the version (`kinuvo --version`), how to reproduce, and the impact. Expect an acknowledgement within a week.

Only the latest release gets fixes.

For safe deployment, see [docs/public-hosting.md](docs/public-hosting.md).
