---
title: "Meet your first Agent"
description: "Choose a Server, model, Identity and Soul in onboarding."
---

Open the app and follow onboarding. Use a management pairing code when configuring a remote Server.

1. **Home:** choose where the Server runs. **This device** appears when the app offers an embedded Server; **Remote server** accepts a Server address or Pairing link and code. Availability depends on the app and build.
2. **Model:** choose a provider and model. Sign in or enter its API key when asked. The provider decides where messages are processed; hosting the Server yourself does not make a cloud model local. See [models](../reference/models.md).
3. **You:** optionally enter your name and occupation. These become User Notes and can be edited later.
4. **Identity:** choose an avatar and give the Agent a name.
5. **Soul:** choose its relationship, voice, initiative, energy and expression. These choices create editable instructions for how it should respond.
6. **Connect:** optionally set up Secret references, Knowledge, Tasks, Notifications, web search, shell and files, and MCP. Only capabilities offered by this Server appear as available. You can return to them in Settings.

Finish with **Meet your Agent** and start a Session. Try telling it something you want it to remember, then review its Memory and User Notes in Settings.

An additional Agent uses the shorter Identity and Soul flow and starts with the selected Agent's model. Each Agent keeps its own Memory, Skills and Sessions. Read [Agents](../concepts/agents.md) and [Approvals](../concepts/approvals.md) before giving it more tools.
